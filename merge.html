How to merge PDF files — private & free

  1. Select two or more PDF files (the order you pick them is the merge order).
  2. Click "Merge & download".
  3. The combined PDF downloads instantly — nothing is uploaded.

Frequently asked questions

Are my PDFs uploaded when I merge them?

No. The files are combined entirely in your browser using the open-source pdf-lib library. They never leave your device.

Is there a limit on file size or number of PDFs?

There is no imposed limit — you are bounded only by your device’s memory. Because nothing is uploaded, even large files merge quickly.

Is merging free? Are there watermarks?

Completely free, no sign-up, no watermarks, no daily quota. The code is open source (MIT).
