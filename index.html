Frequently asked questions

Is AirgapPDF really free?

Yes. Every tool is free with no sign-up, no watermarks, and no file limits. The entire site is open source under the MIT license, so you can audit the code or self-host it.

Are my PDF files uploaded to a server?

No. All PDF processing (merge, split, rotate, compress, delete pages, page numbers, images to PDF) happens locally in your browser using pdf-lib and pdf.js. There is no backend — your files never leave your device, and the tools keep working offline after the first load.

How is this different from other online PDF tools?

Typical "free online PDF" sites upload your document to their servers to process it. AirgapPDF is a static site with no server-side processing at all, which matters for contracts, medical records, financial statements, and anything else you would not email to a stranger.

What about the AI Chat with PDF tool?

Chat with PDF is the one tool that talks to the internet: it sends the document you choose directly from your browser to the Claude API using your own API key. Nothing routes through AirgapPDF servers, because there are none.

Your files are processed locally and never sent to a server. AI tools send only the document you choose to the Claude API.
