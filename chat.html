Chat with PDF

Bring your own Claude API key — the document goes straight from your browser to the API. We never see it.

How to chat with a PDF — private & free

  1. Paste your Claude API key (stored only in this browser).
  2. Choose a PDF and type a question.
  3. Get answers, summaries, and explanations grounded in the document.

Frequently asked questions

Is Chat with PDF private?

The document and your question go directly from your browser to the Claude API over HTTPS — never to AirgapPDF servers, because there are none. Only Anthropic processes the file, under your own API account.

Do I need an API key?

Yes — bring your own Claude API key from the Anthropic Console. It is stored only in your browser’s local storage.

Is it free?

The tool itself is free and open source; you pay only Anthropic’s standard API usage for the tokens you use.
